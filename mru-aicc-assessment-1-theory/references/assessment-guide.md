Official source: framework page 1. Week 3, Google Form questionnaire, /100. The PDF supplies no questions, correct answers, question marks, grade boundaries, or partial-credit rules. Obtain the actual Form quiz key and allocation, a linked instructor answer key, or explicit instructor-provided equivalents before final scoring. Never invent them or derive the correct answer from the cohort majority.

Read all answers for the selected response. Keep stable question IDs and full prompt text so repeated/similar prompts are not confused. Verify that configured question maxima total 100; if they do not, flag the mismatch and ask which allocation governs rather than rescaling silently. Check auto-scored values where available against response/key/marks. Use the form's configured handling of multi-select, accepted alternatives, blanks, and partial credit. Do not add your own all-or-nothing or partial-credit rules.

For open responses, compare the student's meaning with the authoritative expected concepts and scoring guidance. Record the student's answer, expected answer/concepts, evidence for awarded credit, omitted/mistaken concepts, and a corrected explanation. If the key is inadequate for a judgement that affects marks, flag it for instructor clarification; provide learning feedback separately. Missing/unavailable key means Needs clarification and a blank final score.

This assessment has no required video. Review videos only if the actual questionnaire requires one. Never apply the advert or avatar criteria to theory answers.

Detailed report items use one `id` per actual question, not invented generic criteria. Put `expected_answer` in the private assessor report when appropriate; omit it from a student-facing report if the quiz is still active or the user restricts key disclosure.
